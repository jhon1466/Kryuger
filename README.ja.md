# Kryuger

[Español](README.md) · [English](README.en.md) · [中文](README.zh.md) · **日本語**

**ドールズフロントライン**（Steam 英語版クライアント）用のプライベートサーバーです。C#（.NET 8）と LiteDB データベースで書かれています。ゲーム自身のデータテーブルをもとに公式サーバーの処理を再現します。変更は保存され、作戦は本来の目標で勝利判定され、敵は自分のターンに行動します。

> 教育と保存を目的とした非営利プロジェクトです。SunBorn やゲームの運営会社とは関係ありません。ゲームのファイルは含まれていません。クライアントは各自でインストールしてください。

## 使い方：Kryuger GM Tools

**サーバーは Kryuger GM Tools から使います**（`gm-tools` フォルダー）。手動でビルドする必要はありません。

1. `kryuger-gm-tools.exe` を開きます。
2. **開始** を押します。初回はこのリポジトリをダウンロードし、PC に .NET 8 SDK がなければ専用のものをインストールしてサーバーをビルドします。以降は `main` に新しいコミットがあるかだけを確認し、あれば自動で更新します。
3. **プレイ** を押します（または Steam からドールズフロントラインを起動します）。
4. **停止** を押すかアプリを閉じるとリダイレクトが外れ、ゲームは公式サーバーに接続します。

サーバー一式は `%LOCALAPPDATA%\Kryuger` に保存されます。コードは `project`、専用の .NET は `dotnet`、プレイヤーデータは更新対象のコードとは別の `data` に置かれます。

### Kryuger GM Tools でできること

スペイン語・英語・中国語・日本語に対応しています。

- **サーバー：** 開始、停止、更新の確認、ゲームの起動、ライブログ、インストール状態。
- **コントロールセンター：** アカウントとカタログの概要。
- **アカウント：** UID か名前で検索し、資源・ダイヤ・人形・装備・妖精を確認。
- **操作：** カタログ検索で人形・アイテム・装備・妖精・スキン・ダイヤ・資源を付与し、ダイヤ・資源・レベル・名前を設定。プレイヤーがオンラインでも使えます。

サーバーの GM API（`/gm`）は `127.0.0.1` からのみ応答し、`KRYUGER_GM_TOKEN.txt` のトークンが必要です。トークンはサーバー起動時に作成されます。すべての変更は `gm_audit.log` に記録されます。

## 動作環境

- Windows 10/11。
- Steam でインストールしたドールズフロントライン英語版（フォルダーは自動で検出されます）。
- 初回（サーバーと .NET のダウンロード）と Steam のサインインにはインターネット接続が必要です。

## 仕組み

```
src/
  Kryuger.Common/   AuthCode 暗号化（RC4 + MD5 + gzip）、LiteDB データベース、モデル
  Kryuger.Data/     ゲームテーブルの読み込みと製造の計算式
  Kryuger.Server/   ASP.NET Core サーバー：ゲーム API、戦闘ロジック、GM API
  Kryuger.Tests/    暗号化と保存のテスト
  gfl_redirect/     ゲームをローカルサーバーへ向ける version.dll（Rust）
runtime/            ビルド済みの version.dll とログイン用テンプレート
data/gf-data-us/    サーバーが使うゲームテーブル
gm-tools/           Kryuger GM Tools（Tauri 2 + Astro + SolidJS）
```

サーバーは `127.0.0.1`（ポート 5000、80、443）で待ち受けます。起動中はゲームのフォルダーに `version.dll` を置いて通信を転送し、停止すると取り除きます。

## ロードマップ

### 対応済み

**アカウントとログイン**
- Steam でのサインイン、AuthCode 暗号化、公式形式の応答。
- 名前、プロフィール、副官、ゲーム設定、チュートリアル、カリーナのスキン。
- ログインし直したときの作戦の再開。

**工廠と人形**
- 人形の製造（通常・複数・高速）、装備と妖精の製造。
- 部隊、陣形、強化、ダミーリンク、解体、ロック、本来の最大 HP までの修復、スキル訓練、MOD 改造、誓約、スキン。
- 装備と妖精：装備、強化、解体、ロック。

**戦闘**
- 作戦開始、移動、戦闘、補給、ターン終了、撤退。公式応答のすべての項目に対応。
- 戦闘ごとの経験値、レベル、残り HP、評価、好感度。
- 本来の勝利条件：司令部の制圧、敵の全滅、N 体撃破、特定の敵の撃破、指定地点への到達、司令部ノードの制圧、N ラウンドの防衛、ターン制限、人質の救出、建物の目標。
- テーブルの AI に従う敵ターン（待機・巡回・警戒・拡張・追撃・司令部への進攻）と、司令部を失ったときの敗北。
- 人質（解放・護送・救出）と HP が持ち越されるボス。
- 友軍と第三勢力のユニットとその AI、裏切りと変化。
- 建物：所有者の変化、破壊、防御。
- 霧のある夜戦：部隊の視界内だけを表示。
- 作戦・章・イベント・模擬作戦の通常どおりの解放。

**進行と経済**
- 実際の所要時間と報酬による後方支援、自律作戦。
- デイリー・ウィークリー任務と、実際の進行度に基づく実績。
- メール（一覧・受け取り・一括受け取り・削除）、ショップ、バトルパス。

### 未対応

- 建物の能動的な効果（ノードを攻撃するミサイル、砲台、レーダー）。
- 友軍と敵の戦闘。
- 友軍の裏切り・変化の通知形式と、マップから計算される AI パラメーターを公式の通信で確認すること。
- 宿舎の全機能（家具、訪問、電池）とフレンド。
- イベント、シアター、チェス、重装部隊、鉄血、ビークル、探索。
- 強化画面：`Gun/eatGunIndex` の形式は未確認です。

## 手動ビルド（任意）

サーバー（[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)）：

```powershell
dotnet run --project src/Kryuger.Server
```

GM Tools（[Node.js](https://nodejs.org) 20 以上と [Rust](https://rustup.rs)）：

```powershell
cd gm-tools
npm install
npx tauri build --no-bundle
```

実行ファイルは `gm-tools\src-tauri\target\release\kryuger-gm-tools.exe` に作成されます。
